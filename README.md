# Sistema Web Institución Educativa 

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema web para una institución educativa, con el propósito de mejorar la presentación de información institucional y facilitar el acceso a los diferentes servicios ofrecidos por la comunidad educativa.

La plataforma permitirá a estudiantes, padres de familia y visitantes consultar información relevante de la institución de una manera organizada, moderna y accesible.

---

## Objetivo del proyecto

Desarrollar una página web institucional que permita mostrar información académica, administrativa y general de la institución, mejorando la comunicación entre la comunidad educativa y la organización.

---

## Alcance del proyecto

El sistema contará con las siguientes funcionalidades:

- Página principal con información destacada de la institución.
- Sección de información institucional.
- Presentación de servicios educativos.
- Sección de noticias y novedades.
- Información de contacto.
- Diseño adaptable para diferentes dispositivos.
